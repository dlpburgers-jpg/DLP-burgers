# DLP Burgers · V5

Aplicación de pedidos con administración y sincronización mediante Supabase.

- Web: https://dlpburgers-jpg.github.io/DLP-burgers/
- Versión anterior conservada: https://dlpburgers-jpg.github.io/DLP-burgers/version-anterior.html

La versión anterior conserva su almacenamiento local en el mismo navegador. La V5 utiliza un espacio de almacenamiento separado y no borra esos datos.

Esta publicación contiene únicamente los archivos públicos de la aplicación. Las migraciones y los respaldos de la base de datos se gestionan por separado.
